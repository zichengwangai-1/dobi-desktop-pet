# 杜宾桌面助手

macOS 原生桌宠：透明动态视频、拖文件喂狗（移入废纸篓）、按住拖动、右键关闭、幼年点击坐下、成年点击犬吠，以及首次启动满 72 小时自动成长。

- **运行**：双击 `启动杜宾.command`。若 `杜宾.app` 尚未生成，脚本会先本地构建。
- **源码与说明**：[DobiNative/README.md](DobiNative/README.md)。
- **构建**：执行 `DobiNative/build.sh`，需要 macOS 14+ 和 Xcode Command Line Tools。
- **素材**：五个原始 MOV、进食 MP4 和对应的透明 ProRes 4444 视频均纳入版本管理。

本仓库记录原生 macOS 产品；生成的 `.app`、构建缓存、原有 Flutter SDK/原型和其他历史资料保留在本机，不纳入本次版本管理。
