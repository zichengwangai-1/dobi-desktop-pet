# 插花透明素材

通过内置 image_gen 工具生成，保留原始 RGBA PNG，不将黑底或棋盘格当作透明背景。三个素材共享柔和、圆润的黏土玩具风格。

最终素材：`Resources/Images/Flowers/daisy.png`、`pink.png`、`clover.png`。

初次验证：三张 PNG 的 Alpha 最小值均为 0，最大值为 254 或 255。运行时仍检查素材透明通道。桌面组合使用无背景、无阴影的透明窗口；插花工作台使用浅米色背景。
