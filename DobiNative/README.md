# 杜宾 · macOS 桌宠

双击项目根目录的 **杜宾.app** 或 **启动杜宾.command**。运行时不需要 Flutter、Python、ffmpeg 或网络。

- 小狗始终播放动态视频。幼年随机散步、转圈；成年随机散步、犬吠动作。
- 单击幼犬播放坐下，单击成年犬播放犬吠并发声，完成后自动继续随机动作。
- 按住小狗拖动；透明空白区域的点击穿透到桌面。
- 把桌面或 Finder 中的文件、文件夹拖给小狗：成功移入废纸篓后，小狗开始吃狗粮。支持一次拖入多个文件；文件可以从废纸篓找回。
- 连续投喂不会重新起播或切回散步，进食中的新文件会延续下一轮吃饭。停止投喂后自动恢复随机动作，吃饭期间点击不打断进食。
- 幼年投喂使用幼年吃饭视频，成年投喂使用成年吃饭视频。同一次连续进食保持当前年龄形象；进食期间达到成长时间，会在进食结束后切换成年动作。
- 没有与小狗互动时，每隔 5 分钟播放对应年龄的拉屎动画。每次动画结束后，在小狗所在屏幕的随机位置新增一坨便便，已有便便持续累积，无数量上限。
- 右键菜单或菜单栏爪印中的「拉便便」可随时连续点击。每次点击都记录一次演示，按顺序播放并分别新增便便；吃饭或拉屎期间也会保留点击请求，待当前动作完成后继续。
- 点击、右键、拖动和投喂会重置空闲计时。吃饭、拖动或接收文件时暂缓拉屎；拉屎期间的投喂会在动画结束后开始吃饭。
- 每坨便便独立保存，不跟随小狗移动，重启后全部恢复。点击便便只清理这一坨，其余保留，也不会重置小狗的空闲计时。透明边缘的点击穿透到桌面。旧版保存的单坨便便会自动迁移。
- 右键便便选择「屎上雕花」，进入插花小游戏。点击便便表面，随机插入雏菊、粉色小花或三叶草；左侧的花向左倾斜，右侧向右倾斜，顶部朝上，并有轻微弹出效果。没有时间、分数或插花数量限制。
- 插花窗口提供「撤回一朵」「重新插」「插好了」，也支持 Command-Z 撤回。作品实时保存在本机，完成后保留在桌面上；右键可以继续编辑。每坨便便的插花互相独立，单击便便或花朵仍会清理整坨；清理正在编辑的便便时会同时关闭对应窗口。
- 右键小狗，选择「关闭杜宾」。菜单栏爪印也可以关闭、调整大小、静音或找回小狗。
- 首次启动满 72 小时自动成年，包括退出期间。年龄、大小、声音和位置在本机保存，重启不重置。成年后不会因为系统时间回退重新变成幼犬。
- 右键「成长阶段」可选择「幼年期」或「成年期」，立即切换形象并保存，重启后保留。手动选择的阶段不会被自动成长覆盖；选择「自动成长（3 天）」则按首次启动的时间继续成长。进食、拉屎期间切换会从对应阶段动作的开头播放，并保留连续投喂、待投喂和拉便便队列。

## 素材与透明背景

原始文件位于 `../杜宾：小狗动作画面/杜宾/`，它们是带黑色背景的 H.264/HEVC 视频，没有 Alpha 通道。
本版本通过 macOS Vision 对每帧做前景分割，保留深色毛发，将结果编码为 **ProRes 4444 / yuva444p10le / Alpha**。
应用直接解码真正的透明视频，透明窗口无背景、无阴影、无标题栏。切换动作时保留上一帧，避免空白闪烁。
源视频没有被修改。透明结果位于 `Resources/Videos/`，应用内包含相同视频。
进食素材保留小狗和狗粮碗：`幼年期：吃饭.mp4` 取 0.9–2.8 秒，`成年期：吃饭.mov` 取 1.1–3.4 秒的低头进食段循环，避免每轮重新站起。播放器按当前成长阶段选择视频。
拉屎视频完整保留动作：幼年 121 帧，成年 152 帧；成年原片宽画幅先居中裁除两侧黑边，避免拉伸小狗。`Resources/Images/poop.png` 保留用户原图的真实透明通道，独立透明窗口显示，不添加背景或窗口阴影。
插花素材位于 `Resources/Images/Flowers/`，通过内置 image_gen 生成，三张均为真实 RGBA 透明 PNG，生成提示词见 [docs/flower-assets.md](docs/flower-assets.md)。桌面上的便便与花朵保持透明背景，花瓣也参与点击和右键命中；插花工作台采用浅米色背景。素材、解码图像和基础透明度数据共用，已插花便便另缓存小尺寸组合透明度，避免在鼠标移动时反复绘制。
由于原始素材已混合黑底，轮廓仍可能有少量分割误差；若以后提供原始透明导出，可以直接替换对应文件。

## 开发

需要 macOS 14+、Xcode Command Line Tools。当前构建适用于 Apple Silicon。

```sh
./build.sh
CLANG_MODULE_CACHE_PATH=/tmp/dobi-swift-cache SWIFTPM_MODULECACHE_OVERRIDE=/tmp/dobi-swift-cache \
  swift test --disable-sandbox --cache-path /tmp/dobi-spm-cache \
  --config-path /tmp/dobi-spm-config --security-path /tmp/dobi-spm-security
```

重新生成视频仅用于更换原始素材，需要 `ffmpeg`：

```sh
python3 Tools/prepare_assets.py
./build.sh
```

只重新生成进食素材：`python3 Tools/prepare_assets.py --only puppy_eat adult_eat`。
只重新生成拉屎素材：`python3 Tools/prepare_assets.py --only puppy_poop adult_poop`。macOS Vision 分割需要能够访问系统神经引擎的运行环境。

测试覆盖 72 小时成长边界、成年持久化、年龄对应互动和进食、随机动作年龄隔离、拖动不触发点击、连续投喂状态、文件批量移入废纸篓、文件夹去重和符号链接保护。文件测试只操作自行创建的临时文件，并将它们恢复、清理。
`Tools/VerifyFeeding.swift` 使用原生拖放回调、真实废纸篓服务及真实播放器验证整个喂食流程；测试实例传入 `--adult` 可以验证成年喂食。
`Tools/VerifyStageSwitch.swift` 在独立测试 bundle 中验证实际右键菜单、选择持久化、恢复自动成长，以及进食、拉屎时切换阶段后动作与队列继续正常运行，检查实际渲染帧的透明通道。
`IdlePoopTests` 覆盖精确 300 秒触发、连续 100 个自动周期、互动重置、忙碌延后，以及大量连续演示请求不丢失。`Tools/VerifyIdlePoop.swift` 在独立测试 bundle 中使用注入时钟、真实播放器和鼠标事件，验证两个自动周期加三次连续点击累积五坨便便、透明渲染、逐个清理、多坨位置持久化和旧版数据迁移；`--adult` 验证成年流程，不修改正式产品的年龄或设置。便便窗口共享图像和透明度数据，并使用一个鼠标穿透定时器。
原有 `dobipet/` Flutter 原型保留；本产品的可运行 macOS 版本位于 `DobiNative/`。

`FlowerGardenTests` 覆盖左右朝向、无数量上限的插花、撤回与重置、独立作品、持久化和非法坐标。`Tools/VerifyFlowers.swift` 使用实际右键菜单、鼠标事件和按钮验证插花流程、旧版便便恢复、多坨作品重启恢复、编辑期间清理，以及真实透明花瓣的点击穿透。原生验证需要可访问 macOS 窗口服务：

```sh
python3 Tools/run_native_validation.py Flowers /tmp/dobi-flower-editor.png
python3 Tools/run_native_validation.py IdlePoop
python3 Tools/run_native_validation.py IdlePoop --adult
```
